# Results

This directory contains summarized outputs from training runs and experiments.

Version-controlled results may include:

- Evaluation metrics
- Loss summaries
- Comparison tables
- Generated samples
- Figures and plots
- Experiment reports
- Hardware and runtime measurements

Large raw outputs should not be committed directly to Git. Important results should include enough metadata to identify the model, dataset, configuration, random seed, and evaluation procedure used to produce them.

Model weights and checkpoints belong in the `models/` directory rather than here.
